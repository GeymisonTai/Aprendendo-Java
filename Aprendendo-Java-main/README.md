# Projeto Software-Java
Aqui são todas as práticas feitas em Java aprendidas(do básico noções básicas até herença ,Tratamento de execeções,Polimorfismo,Encapulamento e GUI).Dificil mas legal de aprender.O foco é o projeto que vai englobar tudo que aprendi.
Com base no código apresentado, os **requisitos funcionais** podem ser descritos de forma simples da seguinte maneira:

### Requisitos Funcionais

**RF01 – Inicializar o sistema**

* O sistema deve iniciar a aplicação e exibir uma mensagem de boas-vindas no console.

**RF02 – Abrir a interface gráfica**

* O sistema deve abrir a janela principal da aplicação utilizando a biblioteca Swing.

**RF03 – Cadastrar pacientes**

* O sistema deve permitir o registro de pacientes com nome, CPF, e-mail, idade e queixa principal.

**RF04 – Exibir informações dos pacientes**

* O sistema deve permitir visualizar os dados cadastrados dos pacientes.

**RF05 – Descrever a crise existencial do paciente**

* O sistema deve apresentar uma descrição da situação ou queixa informada pelo paciente.

**RF06 – Cadastrar psicólogos**

* O sistema deve permitir registrar psicólogos com dados pessoais, número do CRP, especialização e tempo de experiência.

**RF07 – Exibir informações dos psicólogos**

* O sistema deve permitir visualizar os dados dos psicólogos cadastrados.

**RF08 – Cadastrar psiquiatras**

* O sistema deve permitir registrar psiquiatras com dados pessoais, número do CRM, especialização e tempo de experiência.

**RF09 – Exibir informações dos psiquiatras**

* O sistema deve permitir visualizar os dados dos psiquiatras cadastrados.

**RF10 – Realizar atendimento psicológico**

* O sistema deve permitir que um psicólogo realize o atendimento de um paciente.

**RF11 – Realizar avaliação psiquiátrica**

* O sistema deve permitir que um psiquiatra avalie um paciente.

**RF12 – Prescrever medicação**

* O sistema deve permitir que um psiquiatra registre uma prescrição de medicamento para um paciente.

**RF13 – Gerar relatório de diagnóstico**

* O sistema deve permitir a geração de relatórios diagnósticos dos pacientes.

**RF14 – Exibir a função de cada usuário**

* O sistema deve informar a função desempenhada por cada tipo de usuário (Paciente, Psicólogo ou Psiquiatra).

**RF15 – Validar dados informados**

* O sistema deve validar os dados cadastrados e impedir registros inválidos.

**RF16 – Tratar erros e exceções**

* O sistema deve exibir mensagens de erro quando ocorrerem problemas durante a execução ou no cadastro de informações.

Esses requisitos refletem as funcionalidades evidenciadas no método `main()` e no método de demonstração `exemploDeUsoConsole()`.
